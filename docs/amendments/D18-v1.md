# D18-v1 — PH-19 exact amount representation

**Status:** APPROVED by Tejas, 2026-10-10 IST. The frozen PRD remains unchanged.

The extraction JSON amount is a decimal-rupee string with digits before the decimal point and at most two fractional digits. Convert it deterministically from decimal text to integer paise; reject exponent notation, signs, whitespace, more than two fractional digits, zero, negative values, and values outside the signed PostgreSQL BIGINT paise range. No floating-point conversion is permitted.

This approval resolves amount representation only; category-to-custom-bucket mapping remains open.
