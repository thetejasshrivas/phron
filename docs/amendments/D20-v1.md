# D20-v1 — Approved bucket deletion and reallocation

Founder approval: Tejas, 2026-10-10. Applies to FR-BUCKET-04 / AC-BUCKET-04 only.

1. Mandatory Single Target Reallocation: Deleting a bucket with active current-cycle transactions presents a required modal prompting the user to select an active target discretionary bucket.
2. Atomic Transaction Reassignment: All active transactions from the deleted bucket are updated to the target bucket in a single atomic database transaction.
3. Budget Allocation Absorption: The deleted bucket's monthly allocation merges automatically into the target bucket's monthly allocation, preserving total discretionary budget and ledger conservation (FIT-01).
4. Cascade / Soft Deletion: The empty source bucket is removed/soft-deleted cleanly without foreign key violations.

## Explicitly approved active-cycle supplement

Move the source bucket’s existing active allowance and spent totals into the target along with its transactions, preserving accepted recovery trims and aggregate remaining allowance. Merge monthly baselines as approved; retain the target’s floor; archive the source so historical transactions remain valid. Example: source baseline ₹3,000, trimmed active allowance ₹2,800, spent ₹2,000 → transfer ₹2,800 active allowance and ₹2,000 spent, not ₹3,000 active allowance.

Approval does not authorize remote migrations or redefine historical edit rules.
