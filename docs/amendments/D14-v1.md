## Exact approved terms

1. Distress Priority Override: In State C (Financial Distress), obligations and solvency take precedence. Discretionary want-bucket allowances (Dining Out, Entertainment) are clamped to ₹0 regardless of user-configured recovery floors, and want-goals are locked. Hard floors protect allowances during standard State B overspend recovery, not during genuine insolvency.
2. Baseline Preservation: Configured baseline monthly allocations and hard floors are never deleted from the database schema; they remain saved as the user's target profile.
3. Exit Restoration on Rollover: When Distress Mode disengages upon explicit confirmed salary meeting solvency criteria (L_current >= O_unpaid + CC_accrued and I_sustainable >= O_total), baseline discretionary bucket allocations and their user floors automatically restore for the new cycle.

## Local implementation scope

Pure bucket policy and local snapshot mutation clamp only Dining/Entertainment active allowances, retain floor values, and preserve baseline allocations. Existing confirmed rollover restores baseline rows/floors; classification re-applies the clamp if still insolvent. Nullable goal_kind (WANT/NEED) records explicit classification without guessing old rows. WANT creation/increased funding is guarded while C; WANT rollover contributions pause while still C, preserving held/accumulated money. Existing NEED/unknown rollover guard remains UNAVAILABLE in C, pending separate goal semantics. No goal creation UI/API or remote migration added.
