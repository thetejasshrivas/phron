# D09-v1 — PH-19 extraction method and confidence routing

**Status:** APPROVED by Tejas, 2026-10-10 IST. The frozen PRD remains unchanged.

Payment method may be classified only from an explicit method phrase in the user's source text. If absent or unclear, leave it unknown and do not directly save; return a typed method-confirmation/manual-entry state. Do not default to cash. Only explicit card wording may route to the card lifecycle operation. High/medium/low confidence routing remains deterministic from local exact merchant memory, the approved single-category and multi-category merchant sets, and P2P/unknown-context rules; model-reported confidence is ignored. P2P/unknown-context entries remain uncommitted clarification items.

This approval does not authorize custom category matching or model-selected confidence. Account for explicit method before committing any item.
