# D08-v1 — PH-19 extraction provider privacy scope

**Status:** APPROVED by Tejas, 2026-10-10 IST. The frozen PRD remains unchanged.

PH-19 may use the configured Gemini and Groq free-tier inference services for extraction of sanitized transaction text only, after a truthful user-facing disclosure. Do not transmit balances, income, debt, identity, category budgets, or computed financial deltas. Do not claim zero retention or non-training: disclose that Gemini unpaid-tier prompts/responses may be used to improve products and reviewed by humans, and are retained for abuse monitoring (currently up to 55 days); disclose Groq's default inference handling and possible reliability/abuse logging (currently up to 30 days) unless the actual account's eligible Zero Data Retention control is verified enabled. No live calls with actual personal financial data are authorized by this decision.

This is a scoped privacy decision, not account verification. Provider credentials are absent in this local environment; no live call was made. Public terms must be rechecked before release. The user-facing disclosure/consent flow must exist before any ordinary user's text is sent externally.
