# D19-v1 — Provider timeout budget

**Status:** APPROVED by Tejas on 2026-10-10 IST.

For PH-19 extraction, allow a maximum of four seconds per provider. The Gemini primary request and its one permitted schema retry share the same four-second budget. If Gemini fails, Groq may then use its own four-second budget. Extraction can therefore take approximately eight seconds before database persistence begins. Abort timed-out requests and return the existing typed fallback if no provider succeeds. This decision changes provider timeout budgeting only; it does not authorize financial mutations by a model or alter persistence timeout behavior.

The frozen PRD remains unchanged.
