# D23-v2 — APPROVED by Tejas — 2026-10-12 IST

Tejas explicitly approved the proposed D23-v2 amendment and immediate hotfix deployment on2026-10-12. Changes only D23-v1's local-only speech boundary; frozen PRD unchanged. Optional browser-provider processing requires disclosure and explicit consent. Constructor availability is not a guarantee of functioning recognition on every Chrome,Edge or Safari installation.

Conflict: the hotfix requests standard browser recognition without local-support checks while retaining zero audio uploads. D23-v1 prohibits remote speech services and audio to any provider. Counterexample: Chrome can expose webkitSpeechRecognition and send audio to its recognition web service; constructor presence does not prove local processing. [MDN SpeechRecognition](https://developer.mozilla.org/en-US/docs/Web/API/SpeechRecognition), [processLocally](https://developer.mozilla.org/en-US/docs/Web/API/SpeechRecognition/processLocally), checked2026-10-12.

## Exact proposed approval wording

“PHRON may offer standard browser SpeechRecognition or webkitSpeechRecognition as an optional voice capture path. Before starting that path, disclose that the browser may send microphone audio to its speech provider and obtain explicit user consent in addition to browser microphone permission. Do not claim zero audio uploads or guaranteed local processing for that path. PHRON does not upload or store audio itself, add a transcription service, install recognition models, or enable paid services. Provider retention and browser compatibility are not guaranteed. Typed capture remains available without voice consent; cancel, errors and unsupported browsers preserve existing text. Recognized text is capped at280characters and never saves automatically; it follows the existing privacy, provider-consent and deterministic mutation boundaries. Preserve verified on-device recognition where supported.”

Required tests: consent-before-start, both constructors, mode disclosure, denial/service/no-speech feedback, actual listening-start event, stop/late-result protection,280character bounds and no automatic saving. Run unit/integration, lint/typecheck/build and UI checks. Live voice remains a separate browser/phone verification; mocks do not prove audio locality. Immediate hotfix deployment is operator-authorized as a narrow exception to the evaluator freeze; unrelated deployments remain prohibited.
