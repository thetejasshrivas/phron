# D26-v1 — factual negative cash and immediate distress

Status: APPROVED by Tejas, 2026-10-09 IST. This amendment changes only the
negative-cash outcome of real financial outflows and its direct liquidity
classification.

1. **Ledger Truth & Unclamped Cash:** Real-world cash debits are recorded
   factually. If an outflow exceeds declared liquid cash, `L_current`
   evaluates to its true negative balance. Outflows are never dropped,
   rejected, or truncated merely because the ledger runs negative (FIT-01).
2. **Zero Safe-to-Spend Clamp (FIT-02, FIT-03):** Because `M_liquid < 0`,
   `S_pool` evaluates strictly to 0 paise via
   `max(0, min(M_budget, M_liquid))`. Zero fictional spending permission is
   manufactured.
3. **Immediate Liquidity Distress (State C):** Because
   `L_current < O_unpaid + CC_accrued`, the account immediately flags
   `liquidity_distress = TRUE` and enters State C (Financial Distress) per
   PRD 18.6, locking discretionary want-goals.

Affected clauses/tests: PRD 18.1 and 18.6; FIT-01, FIT-02, FIT-03; D01/D02;
Scenarios 13–14 and the negative-outflow persistence boundary. Domain and
local ordinary-user persistence evidence is recorded in
`docs/evidence/G3/D26/RESULT.md`.
