# D24-v1 — APPROVED — explicit Tejas approval of exact proposed wording, 2026-10-10 IST

Source: PRD §§33–35; permanent commitment kill trigger, metric labels and 21-day cohort protocol.

Exact approved wording:
“Keep the 21-calendar-day pilot and the source cohort of 6–11 explicitly enrolled participants. Measure habit persistence across pilot-relative Days 8–14 and 15–21; call that the two measured weeks within the three-week pilot. Label 1 − swaps / NLP transactions as the no-swap proxy, not independently verified extraction accuracy; report independently labeled extraction accuracy separately and do not fabricate results when no pilot has run. A persistent global safety switch permanently disables proposing and accepting NEW next-cycle commitments once two distinct enrolled pilot users enter State C after previously accepting a next-cycle commitment. Record each qualifying participant once, with a State C transition occurring after that participant’s accepted commitment. Enrollment is an explicit operator/admin action, unavailable to ordinary users. Enforcement is atomic in the database acceptance boundary and read-only proposal boundary. Disabling new commitments preserves existing commitments, deductions, cash/card payments, recovery trims, goal operations and audit history. Ordinary users cannot enroll themselves, modify safety records or re-enable the switch. No pilot is started or real participant enrolled by this implementation.”

Counterexample: deleting existing commitments when disabling the feature would rewrite already accepted budget deductions; checking a client flag alone could allow concurrent or forged acceptance. A no-swap measure is not a truth-labeled accuracy measure.

Required implementation and evidence after explicit approval: switch persistence, two distinct participants/duplicate events, no un-enrolled trigger, post-acceptance State C order, ordinary/anonymous denial, concurrent acceptance vs disable, durable replay/history retained, existing deductions/payments unaffected; privacy-safe counts/booleans only. Local synthetic fixtures only; no remote migration or real pilot.
